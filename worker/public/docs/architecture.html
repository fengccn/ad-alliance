🗄 D1 数据库（五张核心表）

  • sites — 站点：id / site_name / site_url / contact_email / api_key / status / daily_cap
  • ads — 广告：id / site_id / image_url / target_url / status / weight
  • impressions — 曝光日志：ad_id / site_id / ip_hash / created_at
  • clicks — 点击日志：ad_id / site_id / ip_hash / user_agent / created_at
  • stats_daily — 每日统计（可选物化表）

日志只存 ip_hash（SHA-256+盐），保护访客隐私

🛠 管理后台（admin/index.html）

  • 待审广告 — 通过 / 驳回（防违规、防钓鱼污染域名）
  • 站点管理 — 启用 / 暂停 / 调整每日上限 / 查看自身广告
  • 数据看板 — 曝光 / 点击趋势、点击率、Top 站点

与 Worker 同一部署（Static Assets），调 /admin/api/*（X-Admin-Token 鉴权）

🔑 站点自助接口

  • /api/register — 注册站点 + 提交广告素材 + 自身广告(100×100)
  • /api/self — 已激活站点更新自身广告素材（api_key）
  • /api/ads — 已激活站点提交新广告（api_key）
  • /api/stats — 双向统计：
    as_publisher（我展示别人）+ as_advertiser（别人展示我）

🛡 风控与公平性（已在代码中实现）

曝光防刷同 ip_hash 对同站点 1 分钟内只记一次有效曝光
点击防刷同 IP 对同广告 5 分钟内只计一次；用延迟跳转页过滤脚本
人工审核所有站点与广告先 pending，审核通过才 active
每日配额每站点广告每天最多展示 daily_cap 次，防大户垄断
冷启动加权新站注册 7 天内权重 ×1.5，帮助获得初始曝光
异常检测曝光正常但点击率 > 10% 的站点自动标记待审核
⚠ 关键点：右侧伙伴广告的 click_url 必须经过服务器（/click/…）中转，否则无法统计每个站点带来的曝光与点击。左侧自身广告直链本站，无需中转。
